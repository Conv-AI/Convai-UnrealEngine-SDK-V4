# Convai Unreal Engine SDK

## Agent skills

### Issue tracker

Issues and PRDs live as markdown files under `.scratch/<feature-slug>/` in this repo, not GitHub Issues. See `Docs/agents/issue-tracker.md`.

### Triage labels

The canonical five (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), written to each issue file's `Status:` line. See `Docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `Docs/adr/` at the repo root. The `Context/` directory is raw notes, not the glossary. See `Docs/agents/domain.md`.
